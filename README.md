## ⚡ Features
* **Real-Time Rank:** Fetches current Solo/Duo and Flex rank directly from Riot API.
* **Live Match History:** Displays the last 10 games with KDA, CS, and Win/Loss status.
* **Smart Caching:** Handles API rate limits automatically to prevent crashes.
* **Region Locked:** Optimized for SEA/Thailand servers (`sg2` / `th2`).

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, Vanilla JavaScript
* **Backend:** Node.js, Express
* **API:** Riot Games API (League-V4, Match-V5)
